# 英語の語順トレーナー 🔀

英文を**色分けブロック**に分解し、各ブロックに日本語訳をつけて**英語の語順のまま**並べて見せるアプリです。
日本語（テニスを→する）と英語（する→テニスを）で**順番が入れ替わる場所**を体に覚えさせ、
「意識しなくても英語の順番で考えられる」状態を目指します。

## 2つのモード

- 📖 **学習**：英文 → ブロック分解（役割で色分け）＋語順の解説。「英語を隠す」で日本語ブロックだけを見て英語を思い出す自己テストも可能。
- 🔀 **組み立て**：日本語を見て、バラバラのブロックを**英語の順にタップ**して並べる。正解するとマスター登録。語順を“能動的に”訓練。

進捗（学習した文／マスター数）は上部バーで可視化され、端末内（localStorage）に保存されます。

## 収録（118文・語順パターン別／中学全範囲）

- **基本(30)**：be動詞・一般動詞・3単現・現在進行形・過去形・命令文、動詞→目的語、go to/live in、目的語→場所、be動詞や What/Who/How many の疑問文
- **応用(42)**：主語→動詞→目的語→**場所→時**、過去進行形・be going to・助動詞、**不定詞3用法・動名詞**、接続詞(if/because)、比較(as~as)、SVC(look/become)、**疑問詞(When/How)の文頭移動**
- **発展(46)**：受け身、現在完了(経験/完了/継続/進行形)、不定詞発展(too~to/want人to/疑問詞+to)、**分詞・関係代名詞・接触節の後置修飾**、**間接疑問**、仮定法、感嘆文、付加疑問、原形不定詞

> 「語順がこんがらがりやすい」**後置修飾（分詞・関係代名詞）／場所・時の位置／不定詞・動名詞／疑問文の文頭移動**を重点的に厚く配分しています。

## 含まれるファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（118文を内蔵。これ単体で動作） |
| `manifest.json` / `sw.js` | ホーム画面追加・オフライン動作用 |
| `icon-*.png` | アプリアイコン |
| `build_sentences.py` | 文データの生成＆自動検証スクリプト（任意） |
| `sentences.json` | 文データ（生成物） |

## GitHub Pages で公開

1. 新規リポジトリを作成し、上記ファイルを**同じ階層**にアップロード。
2. **Settings → Pages → Branch: `main` / `(root)`** で保存。
3. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## iPhoneでアプリ化（ホーム画面に追加）

1. **Safari** で公開URLを開く → 共有ボタン（□↑）→ **「ホーム画面に追加」**。
2. アイコンから起動すると全画面アプリに。一度開けば**オフラインでも利用可**。

## 文を追加・編集する

`index.html` 内の `const SENTENCES = [ ... ];` を編集します（1文 = 下記の形）。
**ポイント：`blocks` の `en` を左から連結すると、ちょうど英文 `en` になるように**します（＝英語の正しい語順）。

```js
{
  "id": 119,
  "level": "基本",                    // 基本 / 応用 / 発展
  "pattern": "主語+動詞+目的語",        // 画面に表示するパターン名
  "en": "I have a dog.",             // 完成する英文
  "blocks": [
    {"en":"I",     "jp":"私は",   "role":"主語"},
    {"en":"have",  "jp":"飼っている","role":"動詞"},
    {"en":"a dog", "jp":"犬を",   "role":"目的語"}
  ],
  "jp": "私は犬を飼っている。",          // 自然な日本語（意味）
  "point": "動詞→目的語の順",            // 解説の見出し（一言）
  "explain": "「犬を→飼っている」→英語は「have→a dog」。動詞が先、目的語が後ろ。"
}
```

`role` に使える値（色分け）：`主語 / 動詞 / 目的語 / 補語 / 場所 / 時 / 助動詞 / 疑問 / その他`

**Python が使える場合**は `build_sentences.py` の `S` リストに同じ形で追記して
`python3 build_sentences.py` を実行すると、**ブロックの連結が英文と一致するか自動チェック**された上で
`sentences.json` が再生成されます（その内容を `index.html` の `const SENTENCES = [...]` に貼り替え）。
